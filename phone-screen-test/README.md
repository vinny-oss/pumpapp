# Phone Screen Water Tank Test

A beautiful water-filling animation in a phone screen container.

## Features

- **Phone Screen Container**: Exact iPhone 14 Pro dimensions (390px × 844px)
- **Realistic Water Animation**: Smooth 4-second fill with cubic-bezier easing
- **Wave Effects**: Three-layer animated waves for realistic water surface
- **Bubbles**: 8 animated bubbles rising at different speeds and positions
- **Light Effects**:
  - Caustics (light patterns that dance through water)
  - Shimmer effects
  - Light rays from the top
- **Water Gradient**: Multi-layer gradient for depth and realism

## How to Use

1. Open `water-tank.html` in your browser
2. Click the **FILL** button
3. Watch the water fill up like a real fish tank!
4. **Double-click** on the screen to reset and fill again

## Technical Details

- Pure HTML/CSS/Vanilla JavaScript
- No external dependencies
- Smooth animations using CSS keyframes
- SVG wave patterns for realistic water surface
- Radial gradients for bubble effects
